# アクセシビリティ方針とチェックリスト

対象基準: WCAG 2.1 レベル AA

## 実装済みの仕組み

| 項目                 | 実装                                                                                                                        |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| グラフ UI の代替操作 | ノード一覧（`NodeList`）からキーボードのみで全ノードへアクセス可能                                                          |
| 自動テスト           | jest-axe による axe 検証（`tests/accessibility.test.tsx`）+ Lighthouse CI の a11y スコア 0.9 未満でエラー                   |
| フォーカス管理       | ノード選択時にパネル見出しへフォーカス移動、閉じると元の要素へ復帰（`useNodeSelection`）                                    |
| フォーカストラップ   | モバイルのボトムシート表示中は Tab をパネル内に閉じ込め（`useFocusTrap`）                                                   |
| キーボード操作       | Escape で詳細パネルを閉じる                                                                                                 |
| フォーカス可視化     | `:focus-visible` に 3px アウトライン（`global.css`）                                                                        |
| アニメーション抑制   | `prefers-reduced-motion: reduce` で CSS トランジション停止 + グラフのレイアウトを事前計算して整列アニメーションを表示しない |

## リリース前セルフチェックリスト

### 知覚可能

- [ ] 新しい UI 要素に適切なラベル（aria-label / 関連付いた label）があるか
- [ ] テキストと背景のコントラスト比が 4.5:1 以上か（大きな文字は 3:1）
- [ ] 色だけで情報を伝えていないか（グラフの凡例に形状の区別があるか）

### 操作可能

- [ ] すべての機能がキーボードのみで操作できるか（グラフ操作はノード一覧で代替）
- [ ] フォーカス順序が視覚的な順序と一致しているか
- [ ] フォーカスが見えるか（focus-visible のアウトライン）
- [ ] モーダル表示中にフォーカスが背後に漏れないか

### 理解可能

- [ ] html の lang 属性がロケールと一致しているか（プリレンダで `/en` は `lang="en"`）
- [ ] エラーメッセージが具体的で、回復手段を示しているか

### 堅牢

- [ ] `npm run test`（jest-axe）が通るか
- [ ] Lighthouse CI の accessibility スコアが 0.9 以上か

## スクリーンリーダー実機確認の手順

四半期に一度、または大きな UI 変更時に実施する。

1. **Windows + NVDA（無料）+ Chrome**
   - `/ja` を開き、見出しジャンプ（H キー）でページ構造を確認
   - Tab 移動で検索 → フィルタ → ノード一覧の順に到達できること
   - ノード一覧からノードを開き、パネル見出しが読み上げられること
   - Escape で閉じた際、元のボタンへフォーカスが戻ること
2. **iOS VoiceOver + Safari**（モバイルレイアウト）
   - ボトムシート表示中にシート外の要素へスワイプ移動できないこと
   - 「閉じる」ボタンに到達・実行できること
3. 発見した問題は `a11y` ラベル付きで issue 化する
